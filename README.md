# Smartsies
Built and deployed a ML-based system using Scikit-learn models to predict fishing locations, integrated with OpenWeather API and Google Generative AI for intelligent recommendations.
User → React Frontend → FastAPI Backend →
    → ML Models (Prediction)
    → Weather API
    → Gemini AI
→ Response → Frontend UI
